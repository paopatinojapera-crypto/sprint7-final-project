# sprint7-final-project
Análisis ConnectaTel
- El objetivo es evaluar el comportamiento de los clientes de una empresa de telecomunicaciones en Latinoamérica, ConnectaTel. Trabajaremos con información registrada hasta el año 2024, lo cual permitirá analizar el comportamiento del negocio dentro de ese periodo.
Bases de datos utilizadas:
- plans.csv → información de los planes actuales (precio, minutos incluidos, GB incluidos, costo por extra)
- users.csv → información de los clientes (edad, ciudad, fecha de registro, plan, churn)
- usage.csv → detalle del uso real de los servicios (llamadas y mensajes)
Detalle de análisis realizado:
- Se exploraron las bases de datos, se identificaron % de valores ausentes, y de acuerdo a la severidad, se decidió si imputarlos o no considerarlos.
- Finalmente, se hicieron nuevas clasificaciones de clientes de acuerdo a uso y edad, y se construyó un perfil estadístico de los clientes. También se detectaron outliers y se realizaron sugerencias respecto a estos hallazgos.
